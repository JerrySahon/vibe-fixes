**Сам.** Открой fix и иди по шагам A, B, C.

**Через ИИ.** В каждой папке лежит `AGENT.md`. Скинь его своему Claude или ChatGPT, и он проведёт тебя по шагам, попросит скрин, если что-то пошло не так, и заранее знает все грабли.
