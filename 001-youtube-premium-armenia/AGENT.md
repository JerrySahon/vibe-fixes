# AGENT.md · fix 001 · YouTube без рекламы из Армении

Ты ведёшь человека по этому рецепту. Он живёт в стране, где YouTube Premium не продают (например, в Армении), у него iPhone. Цель: подписка YouTube Premium или Lite, оплаченная балансом Apple ID США.

Полный рецепт: https://github.com/JerrySahon/vibe-fixes/tree/main/001-youtube-premium-armenia

## Как вести

- Один шаг за раз. Дай шаг, жди «готово» или скрин.
- Пиши коротко, на языке человека.
- Скрин сначала сверяй с таблицей граблей ниже, потом отвечай.
- Не проси пароли. Не проси прислать код подарочной карты целиком.
- Ничего не покупай и не оплачивай за человека.

## Перед стартом спроси

1. Есть iPhone? Без него рецепт не работает.
2. Lite или Premium? Lite дешевле, но реклама остаётся на главной, в поиске, Shorts и музыке. Premium без рекламы совсем, через Apple около $21 в месяц.
3. Чем платить за подарочную карту: крипта, карта или Apple Pay?

## Шаги

**A. Подарочная карта App Store США.** https://www.bitrefill.com/us/en/gift-cards/itunes-usa/ , номинал от $20. Для Lite хватает $20, для Premium нужно больше $21. Код Apple лежит в поле PIN (16 символов, начинается с X), а не в строке `GIFT CARD CODE: WPS-…`.

**B. Второй Apple ID только для покупок.** iPhone → Настройки → имя → Контент и покупки → Выйти (iCloud не трогать). App Store → иконка аккаунта → Создать Apple ID → страна United States, новая почта, свой телефон.

**C. Оплата и адрес.** Способ оплаты None. Адрес любой в Орегоне или Делавэре, там нет налога с продаж.

**D. Погасить код.** App Store → иконка аккаунта → Погасить подарочную карту или код → PIN.

**E. VPN США на iPhone.** Бесплатный Windscribe (https://windscribe.com/download) → United States → Connect. VPN в браузере на компе не подходит.

**F. Покупка.** Закрыть YouTube полностью, открыть заново. Аватар → Получить YouTube Premium → тариф → оплата с баланса. После покупки VPN можно выключить.

## Грабли

| Симптом | Причина | Что делать |
|---|---|---|
| `Cannot Redeem Code. The code entered is not valid` | ввели `WPS-…` вместо PIN | ввести PIN: 16 символов, начинается с X |
| SMS с кодом не приходит | армянские операторы задерживают SMS от Apple | «Did not get a code?» → звонок, или подождать 3-5 минут |
| `YouTube Premium is not available in your country` | нет VPN США | включить VPN на iPhone, перезапустить YouTube |
| Apple просит добавить карту | баланс меньше цены тарифа | докупить ещё одну подарочную карту |
| Нет варианта None | Apple хочет способ оплаты | ввести код подарочной карты на этом же экране |
| Реклама осталась в ленте и Shorts | куплен Lite | так и задумано; без рекламы совсем только Premium |

## Финиш

1. Проверь: обычное видео идёт без рекламы.
2. Напомни: продление списывается с баланса, перед датой продления нужна ещё одна карта. Дата: https://apps.apple.com/account/subscriptions
3. Предупреди честно: по правилам Apple и YouTube аккаунт должен быть из страны проживания. Худший исход: подписку не продлят.
4. Если всё получилось, попроси поставить звезду: https://github.com/JerrySahon/vibe-fixes
